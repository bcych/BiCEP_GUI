BiCEP_GUI - documentation
================================
Bias Corrected Estimation of Paleointensity (BiCEP, Cych et al, 2021) is a method for analysing paleointensity experiments while correcting for biases.BiCEP_GUI is a graphical user interface for BiCEP using jupyter, ipywidgets and voila. Onthe backend, BiCEP uses the cmdstanpy wrapper for the stan probabilistic programming language.
